The Day 隐私政策

最后更新：2026年7月

The Day 是一款本地优先的倒数日与纪念日应用。我们尊重并保护用户隐私，本政策说明应用如何处理您的数据。

一、本地数据

The Day 将所有用户数据保存在应用私有目录中，包括：
- 事件信息（名称、日期、分类、备注）
- 用户导入的背景图片和分类封面
- 应用设置和新建草稿
- 小组件图片缓存

这些数据存储在 Android 应用沙箱内，其他应用无法直接访问。

二、图片

- 用户通过系统图片选择器选择日子背景图片或分类封面，无需授予应用读取整个相册的权限
- 选择或更换图片后，裁剪过程由 uCrop 在设备本地完成
- 裁剪时会在应用缓存目录创建原图副本和临时裁剪文件；导入完成后，这些缓存文件会被删除
- 应用会在私有图片目录同时保存保留的原图和 uCrop 输出图片，并额外保存首页与详情页的构图参数
- 取消裁剪或裁剪失败不会替换原有图片，相关临时文件会被清理
- 导入后的原图与裁剪图均保存在应用私有目录，不会因选择或裁剪功能上传到任何服务器
- 图片只在本地用于事件卡片、事件详情、分类封面、桌面小组件和纪念图

三、通知和小组件

- 提醒通知由系统本地闹钟触发，不涉及网络请求
- 桌面小组件只读取本机事件数据
- 不使用分析、广告或跟踪服务

四、应用更新

The Day 支持应用内更新功能：
- 只有用户主动点击"检查更新"才会访问网络
- 更新信息从 GitHub Release 获取
- 下载更新时访问 GitHub 资产地址
- GitHub 可能收到 IP、时间和 User-Agent 等信息
- 不上传任何用户数据（事件、日期、分类、笔记、提醒或图片）
- APK 保存在应用专属目录，安装由 Android 系统确认

五、纪念图分享与保存

- 只有用户主动点击分享或保存操作时，应用才会生成纪念图
- 文字和图片分享通过 Android 系统分享面板完成
- 用户选择的接收应用会获得相应内容，并按该应用自己的隐私规则处理
- 分享图片会先写入应用缓存目录，并通过临时 content:// 权限提供给接收应用
- 保存到相册时，纪念图会写入系统图片库的 Pictures/The Day 目录
- 应用不会自动上传、发送或公开事件内容与图片

六、权限

The Day 可能请求以下权限：
- 通知权限（Android 13+）：用于发送提醒通知
- 旧版 Android 的外部存储写入权限：仅用于把纪念图保存到系统相册；新版 Android 不需要此权限

选择背景图片和分类封面使用 Android 系统图片选择器，不要求读取整个相册。相关权限只在用户主动使用对应功能时处理。

七、数据删除

用户可以通过以下方式删除数据：
- 在设置页面"清空全部事件"
- 在系统设置中清除应用数据
- 卸载应用

以上操作会永久删除所有本地数据，无法恢复。

八、第三方服务

The Day 不使用以下第三方服务：
- 广告平台
- 分析工具
- 社交登录
- 云存储
- 支付系统
- 推送通知服务

九、联系方式

如有隐私相关问题，请通过 GitHub 仓库提交 Issue：
https://github.com/rekjorekjo/TheDay

十、政策变更

本政策如有重大变更，将在应用更新说明中通知用户。建议定期查看本政策以了解最新信息。
