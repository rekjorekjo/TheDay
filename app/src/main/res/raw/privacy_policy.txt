此日隐私政策

最后更新：2026年8月

此日是一款本地优先的倒数日与纪念日应用。我们尊重并保护用户隐私，本政策说明应用如何处理您的数据。

一、本地数据

此日将用户数据保存在应用私有目录中，包括：
- 日子信息（名称、日期、分类、备注、重复、提醒和置顶状态）
- 用户导入的日子背景图片和分类封面
- 纪念册、纪念碑及其排序等配置
- 应用设置和新建草稿
- 小组件配置与图片缓存

这些数据存储在 Android 应用沙箱内。此日不提供账号、云同步、广告或分析服务，也不会主动把上述内容上传到服务器。

二、图片

- 用户通过 Android 系统图片选择器选择日子背景图片或分类封面，无需授予应用读取整个相册的权限
- 选择或更换图片后，裁剪过程由 uCrop 在设备本地完成
- 裁剪时可能在应用缓存目录创建原图副本和临时裁剪文件；导入完成后会清理不再需要的临时文件
- 应用私有图片目录会同时保存未裁剪原图和裁剪结果，以支持后续“重新裁剪”
- 取消裁剪或裁剪失败不会替换原有图片
- 导入后的原图与裁剪图均保存在应用私有目录，不会因选择或裁剪功能上传到服务器
- 图片只在本地用于日子卡片、详情、分类封面、桌面小组件、纪念册和导出图片

三、通知和小组件

- 提醒通知由 Android 本地机制触发，不依赖远程推送服务
- 设备重启后，应用可根据本地数据恢复提醒计划
- 桌面小组件只读取本机事件和图片数据
- 不使用分析、广告或跟踪服务

四、应用更新

此日支持启动时自动检查版本，也支持用户主动发起的应用内更新：
- 应用启动时会访问更新服务查询最新版本；只检查版本，不会自动下载 APK
- 用户也可以主动检查更新、升级 Edition，并在确认后开始下载
- 更新信息和 APK 从 GitHub Releases 获取
- GitHub 可能收到 IP、访问时间和 User-Agent 等常规网络信息
- 此日不会随更新请求上传事件、日期、分类、备注、提醒、纪念册、纪念碑或图片内容
- APK 下载到应用专属目录，随后由 Android 系统安装界面向用户确认安装

五、分享与保存

- 只有用户主动点击分享或保存时，应用才会生成对应的文字或图片内容
- 分享操作通过 Android 系统分享面板完成
- 用户选择的接收应用会获得相应内容，并按该应用自己的隐私规则处理
- 分享图片会先写入应用缓存目录，并通过临时 content:// 权限提供给接收应用
- 保存到相册时，图片会写入系统图片库的 Pictures/The Day 目录（为兼容历史版本，目录名继续沿用 The Day）
- 应用不会自动上传、发送或公开用户的事件内容与图片

六、权限

此日可能使用以下 Android 权限或系统能力：
- 通知权限（Android 13+）：新安装首次打开时请求，用于本地日子提醒和应用更新通知
- 网络访问：用于启动时的版本检查、用户主动检查更新，以及用户确认后的 APK 下载
- 安装应用包能力：用户选择安装更新时，交由 Android 系统安装界面处理
- 设备启动广播：设备重启后恢复本地提醒计划

选择背景图片和分类封面使用 Android 系统图片选择器，不要求读取整个相册。

七、数据删除

用户可以通过以下方式删除数据：
- 在应用设置中使用“清空全部事件”删除全部日子
- 单独删除日子、分类、纪念册或纪念碑内容
- 在 Android 系统设置中清除应用数据
- 卸载应用时选择不保留应用数据

部分 Android 系统在卸载时可能提供“保留应用数据”选项；是否保留由用户在系统界面中决定。已删除或已清除的数据通常无法恢复，请在操作前确认是否仍需要保留。

八、第三方服务

此日不使用以下服务：
- 广告平台
- 分析与行为跟踪工具
- 社交登录
- 云存储或账号同步
- 支付系统
- 远程推送通知服务

应用更新使用 GitHub Releases；用户主动通过系统分享面板把内容发送到其他应用后，接收方的处理方式由对应应用决定。

九、联系方式

如有隐私相关问题，请通过 GitHub 仓库提交 Issue：

十、政策变更

本政策如有重大变更，将在应用更新说明中提示用户。
